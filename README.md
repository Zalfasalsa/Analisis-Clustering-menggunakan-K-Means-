# Analisis-Clustering-menggunakan-K-Means-
Proyek ini membahas penerapan metode K-Means Clustering untuk melakukan pengelompokan data gempa bumi (Global Earthquakes Seismic Dataset).  Tujuan dari proyek ini adalah mengelompokkan data gempa bumi berdasarkan karakteristik tertentu sehingga dapat diketahui pola dan kelompok data yang memiliki kemiripan.
